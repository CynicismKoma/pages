一、起因

之前电脑装的JDK是1.7版本，由于业务需要，需要安装JDK1.8版本。可我又不想把之前的JDK1.7卸载掉。于是试着两个版本共存。

二、探索

众所周知，想要查看JDK是否安装配置成功，需要再dos窗口中输入 java -version。未装JDK1.8之前如下图所示。 

在安装JDK1.8之后，还没有在环境中配置JDK1.8的信息。但是执行 java -version会看到JDK1.8的信息。

这是为何？真是奇了怪了。。

三、解决：

原因：

在安装JDK1.8之后，会自动将java.exe、javaw.exe、javaws.exe三个可执行文件复制到C:\Windows\System32目录。由于这个目录在WINDOWS环境变量中的优先级高于path设置的环境变量优先级。

解决方案：

将C:\Windows\System32目录下的三个可执行文件删除。

注意：当你按照上述操作之后，可能会意外的发现，然并卵。不要着急，首先先把dos窗口关闭，然后将环境path中的%JAVA_HOME%\bin;%JAVA_HOME%\jre\bin;放到最前面。最后重新打开dos窗口，输入java -version就会看到JDK1.7的相关信息啦。（此时JDK1.8环境中还没有配置） 

二、切换JDK版本。

之前已经在系统变量中添加了JAVA_HOME，并配置了JDK1.7的安装路径。现在需要再系统变量中添加新的变量JAVA_HOME1.8。并配置JDK1.8的安装路径。当你想切换到JDK1.8的环境中时，只需要将JAVA_HOME换成JAVA_HOME1.8即可。

注意：一定要把%JAVA_HOME%\bin;%JAVA_HOME%\jre\bin;放到最前面。否则会出错的。
