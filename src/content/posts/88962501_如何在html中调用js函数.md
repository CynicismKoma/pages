HTML组成网页，CSS组织网页，Javascript可以给网页添加复杂操作。

首先要明白，HTML是静态的，要想实现复杂的可变的操作（比如函数，计算结果等）必须使用Javascript进行操作。

Q.如何在Html中获取Javascript函数的值

HTML是静态的，即使将Javascript函数写入HTML,也不会得到函数的结果.

<!DOCTYPE html>  
<html>  
<body>  
  
<p id="demo">demo()</p>  
<script>  
function demo(){  
return "cool"   
}  
</script>  
</body>  
</html>
