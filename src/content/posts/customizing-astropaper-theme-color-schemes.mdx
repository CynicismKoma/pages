本指南介绍了如何启用或禁用明暗模式，以及如何自定义整个网站的配色方案。

## 目录

## 启用/禁用明暗模式

AstroPaper 主题默认包含明暗模式。可以在 `astro-paper.config.ts` 中禁用此默认行为：

```ts file="astro-paper.config.ts"
export default defineAstroPaperConfig({
  // ...
  features: {
    lightAndDarkMode: true, // [!code highlight]
    // ...
  },
});
```

要禁用"明暗模式"，将 `features.lightAndDarkMode` 设置为 `false`。禁用后，网站将仅使用 `src/styles/theme.css` 中定义的亮色配色方案。

## 自定义配色方案

AstroPaper 主题的亮色和暗色配色方案均在 `src/styles/theme.css` 中定义。

```css file="src/styles/theme.css"
/* 亮色主题值 */
:root,
[data-theme="light"] {
  --background: #fdfdfd;
  --foreground: #282728;
  --accent: #006cac;
  --accent-foreground: #ffffff;
  --muted: #e6e6e6;
  --muted-foreground: #6b7280;
  --border: #ece9e9;
}

/* 暗色主题值 */
[data-theme="dark"] {
  --background: #212737;
  --foreground: #eaedf3;
  --accent: #ff6b01;
  --accent-foreground: #ffffff;
  --muted: #343f60;
  --muted-foreground: #afb9ca;
  --border: #ab4b08;
}
```

`:root` 和 `[data-theme="light"]` 选择器定义亮色配色方案，而 `[data-theme="dark"]` 定义暗色配色方案。

要自定义自己的配色方案，在 `:root, [data-theme="light"]` 内指定亮色颜色，在 `[data-theme="dark"]` 内指定暗色颜色。

以下是每个颜色属性的详细说明：

<ResponsiveTable variant="minimal" class="max-sm:-mx-4 [&_td]:first-of-type:text-nowrap">

| 颜色属性              | 定义与用途                                                    |
| --------------------- | ----------------------------------------------------------- |
| `--background`        | 网站的主色。通常是主要的背景色。                                |
| `--foreground`        | 网站的次要颜色。通常是文本颜色。                                |
| `--accent`            | 强调色。用于链接、悬停状态和交互元素。                           |
| `--accent-foreground` | 显示在 `--accent` 背景之上的前景色。                           |
| `--muted`             | 柔和背景色。用于卡片、标签和悬停状态。                           |
| `--muted-foreground`  | 显示在 `--muted` 背景之上的文本颜色。                           |
| `--border`            | 边框颜色。用于分割线和视觉分隔。                                |

</ResponsiveTable>

以下是更改亮色配色方案的示例：

```css file="src/styles/theme.css"
/* ... */
:root,
[data-theme="light"] {
  --background: #f6eee1;
  --foreground: #012c56;
  --accent: #e14a39;
  --accent-foreground: #ffffff;
  --muted: #efd8b0;
  --muted-foreground: #6b7280;
  --border: #dc9891;
}
/* ... */
```
