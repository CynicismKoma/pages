本指南涵盖了 AstroPaper 中可用的配置选项——从网站元数据和功能标志到字体、社交链接和布局设置。

## 目录

## 配置 astro-paper.config.ts

所有站点范围的配置都位于项目根目录的 `astro-paper.config.ts` 中。使用 `defineAstroPaperConfig()` 获得完整的 IntelliSense 支持：

```ts file="astro-paper.config.ts"
import { defineAstroPaperConfig } from "./src/types/config";

export default defineAstroPaperConfig({
  site: {
    url: "https://your-site.com/", // 替换为你的部署 URL
    title: "AstroPaper",
    description: "一个极简、响应式且 SEO 友好的 Astro 博客主题。",
    author: "Sat Naing",
    profile: "https://satnaing.dev",
    ogImage: "default-og.jpg",
    lang: "en",
    timezone: "Asia/Bangkok",
    dir: "ltr",
  },
  posts: {
    perPage: 4,
    perIndex: 4,
    scheduledPostMargin: 15 * 60 * 1000, // 15 分钟
  },
  features: {
    lightAndDarkMode: true,
    dynamicOgImage: true,
    showArchives: true,
    showBackButton: true,
    editPost: {
      enabled: true,
      url: "https://github.com/satnaing/astro-paper/edit/main/",
    },
    search: "pagefind",
  },
  socials: [
    { name: "github", url: "https://github.com/satnaing/astro-paper" },
    { name: "x", url: "https://x.com/username" },
    { name: "linkedin", url: "https://www.linkedin.com/in/username/" },
    { name: "mail", url: "mailto:yourmail@gmail.com" },
  ],
  shareLinks: [
    { name: "whatsapp", url: "https://wa.me/?text=" },
    { name: "facebook", url: "https://www.facebook.com/sharer.php?u=" },
    { name: "x", url: "https://x.com/intent/post?url=" },
    { name: "telegram", url: "https://t.me/share/url?url=" },
    { name: "mail", url: "mailto:?subject=See%20this%20post&body=" },
  ],
});
```

### `site` 选项

<ResponsiveTable>

| 选项                | 描述                                                                                                                   |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `url`               | 你部署的网站 URL。用于规范 URL、OG 图片 URL、RSS 源和站点地图。生产环境中必须正确设置。                                  |
| `title`             | 你的站点名称。                                                                                                         |
| `description`        | 你的站点描述。对 SEO 和社交媒体分享有用。                                                                              |
| `author`            | 你的名字。用作默认文章作者。                                                                                            |
| `profile`           | 你的个人/作品集网站 URL，用于结构化数据。如果没有，设置为 `undefined`。                                                  |
| `ogImage`           | `/public` 中的默认 OG 图片文件名（例如 `"default-og.jpg"`）。当未设置文章特定 OG 图片且 `dynamicOgImage` 禁用时使用。   |
| `lang`              | `<html lang="...">` 的 HTML ISO 语言代码。默认为 `"en"`。                                                              |
| `timezone`          | 文章日期的 IANA 时区（例如 `"Asia/Bangkok"`）。确保在 localhost 和部署站点上时间戳一致。                                  |
| `dir`               | `<html dir="...">` 的文本方向。支持 `"ltr"` | `"rtl"` | `"auto"`。                                              |
| `googleVerification` | Google Search Console 验证 meta 标签值。可选。优先级高于 `PUBLIC_GOOGLE_SITE_VERIFICATION` 环境变量。                  |

</ResponsiveTable>

### `posts` 选项

<ResponsiveTable>

| 选项                 | 描述                                                                                                             |
| -------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `perPage`            | 分页列表页面上每页显示的文章数。默认为 `4`。                                                                      |
| `perIndex`           | 首页"最近文章"区域显示的文章数。默认为 `4`。                                                                      |
| `scheduledPostMargin` | 未来 `pubDatetime` 在此时间窗口内（毫秒）的文章被视为已发布。默认为 15 分钟（`15 * 60 * 1000`）。                  |

</ResponsiveTable>

### `features` 选项

<ResponsiveTable>

| 选项              | 描述                                                                                                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lightAndDarkMode` | 启用或禁用明暗模式切换。默认为 `true`。                                                                                                                                                     |
| `dynamicOgImage`   | 当 frontmatter 中未指定 `ogImage` 时，为每篇文章生成动态 OG 图片。默认为 `true`。详见[权衡说明](https://astro-paper.pages.dev/posts/dynamic-og-image-generation-in-astropaper-blog-posts/#trade-off)。 |
| `showArchives`     | 显示 `/archives` 页面及其头部链接。默认为 `true`。                                                                                                                                           |
| `showBackButton`   | 在文章页面上显示"返回"按钮。默认为 `true`。                                                                                                                                                 |
| `editPost`         | 文章标题下方显示的"编辑页面"链接。设置 `enabled: true` 并提供仓库编辑 URL 的 `url` 基础路径。每篇文章可通过 `hideEditPost` frontmatter 覆盖。                                               |
| `search`           | 搜索提供程序。`"pagefind"` 为默认值。设置为 `false` 可完全禁用搜索。                                                                                                                         |

</ResponsiveTable>

## 更新布局宽度

整个博客的默认 `max-width` 为 `768px`（`max-w-3xl`）。如果你想更改它，更新 `src/styles/global.css` 中的 `max-w-app` 工具类：

```css file="src/styles/global.css"
@utility max-w-app {
  /* [!code --:1] */
  @apply max-w-3xl;
  /* [!code ++:1] */
  @apply max-w-4xl xl:max-w-5xl;
}
```

你可以在 [Tailwind CSS 文档](https://tailwindcss.com/docs/max-width) 中探索更多 `max-width` 值。

## 配置 Logo 或标题

![指向网站 Logo 的箭头](https://res.cloudinary.com/noezectz/v1663911318/astro-paper/AstroPaper-logo-config_goff5l.png)

有 3 种选择：

### 选项 1：网站标题文本

这是最简单的选项。更新 `astro-paper.config.ts` 中的 `site.title`。

### 选项 2：Astro 的 SVG 组件

如果你想使用 SVG Logo，可以使用此选项。

- 首先在 `src/assets/` 目录中添加 SVG。（例如 `src/assets/dummy-logo.svg`）
- 然后在 `Header.astro` 中导入该 SVG

  ```astro file="src/components/Header.astro"
  ---
  // ...
  import DummyLogo from "@/assets/dummy-logo.svg";
  ---
  ```

- 最后，用导入的 Logo 替换 `{config.site.title}`。

  ```html
  <a
    href="/"
    class="absolute py-1 text-left text-2xl leading-7 font-semibold whitespace-nowrap sm:static"
  >
    <DummyLogo class="scale-75 dark:invert" />
    <!-- {config.site.title} -->
  </a>
  ```

这种方法的最佳之处在于你可以根据需要自定义 SVG 样式。在上面的示例中，你可以看到 SVG Logo 颜色如何在暗色模式下反转。

### 选项 3：Astro 的 Image 组件

如果你的 Logo 是图片但不是 SVG，你可以使用 Astro 的 Image 组件。

- 在 `src/assets/` 目录中添加你的 Logo。（例如 `src/assets/dummy-logo.png`）
- 在 `Header.astro` 中导入 `Image` 和你的 Logo

  ```astro file="src/components/Header.astro"
  ---
  // ...
  import { Image } from "astro:assets";
  import dummyLogo from "@/assets/dummy-logo.png";
  ---
  ```

- 然后，用导入的 Logo 替换 `{config.site.title}`。

  ```html
  <a
    href="/"
    class="absolute py-1 text-left text-2xl leading-7 font-semibold whitespace-nowrap sm:static"
  >
    <image src="{dummyLogo}" alt="我的博客" class="dark:invert" />
    <!-- {config.site.title} -->
  </a>
  ```

使用这种方法，你仍然可以使用 CSS 类调整图片的外观。但这可能并不总是符合你的需求。如果你需要根据明暗模式显示不同的 Logo 图片，请查看 `Header.astro` 组件中如何处理明暗图标。

## 配置社交链接

![指向社交链接图标的箭头](https://github.com/user-attachments/assets/8b895400-d088-442f-881b-02d2443e00cf)

社交链接在 `astro-paper.config.ts` 的 `socials` 数组中配置。每个条目需要一个与 `src/assets/icons/socials/` 中 SVG 文件名匹配的 `name` 和一个 `url`：

```ts file="astro-paper.config.ts"
export default defineAstroPaperConfig({
  // ...
  socials: [
    { name: "github", url: "https://github.com/satnaing/astro-paper" },
    { name: "x", url: "https://x.com/username" },
    { name: "linkedin", url: "https://www.linkedin.com/in/username/" },
    { name: "mail", url: "mailto:yourmail@gmail.com" },
  ],
});
```

要添加默认值中没有的社交平台，将其 SVG 图标添加到 `src/assets/icons/socials/` 并添加一个条目到数组中。`name` 必须与 SVG 文件名一致（不带 `.svg` 扩展名）。

## 配置分享链接

![指向分享链接图标的箭头](https://github.com/user-attachments/assets/4f930b68-b625-45df-8c41-e076dd2b838e)

分享链接在 `shareLinks` 数组中配置。每个条目需要一个 `name`（与 `src/assets/icons/socials/` 中的 SVG 匹配）和一个基础 `url`，文章 URL 会附加在其后：

```ts file="astro-paper.config.ts"
export default defineAstroPaperConfig({
  // ...
  shareLinks: [
    { name: "whatsapp", url: "https://wa.me/?text=" },
    { name: "facebook", url: "https://www.facebook.com/sharer.php?u=" },
    { name: "x", url: "https://x.com/intent/post?url=" },
    { name: "telegram", url: "https://t.me/share/url?url=" },
    { name: "mail", url: "mailto:?subject=See%20this%20post&body=" },
  ],
});
```

## 配置字体

AstroPaper 使用 Astro 的[字体 API](https://docs.astro.build/en/guides/fonts/)，默认字体为 [Google Sans Code](https://fonts.google.com/specimen/Google+Sans+Code)。这提供了跨所有平台的一致排版，并具有自动字体优化功能，包括预加载和缓存。

### 使用默认字体

字体在 `astro.config.ts` 中自动配置，并在 `Layout.astro` 中加载。使用默认的 Google Sans Code 字体无需额外配置。

### 自定义字体

要使用不同的字体，更新三个位置：

1. **更新 `astro.config.ts` 中的字体配置：**

```ts file="astro.config.ts"
import { defineConfig, fontProviders } from "astro/config";

export default defineConfig({
  // ...
  fonts: [
    {
      name: "你的字体名称", // [!code highlight]
      cssVariable: "--font-your-font", // [!code highlight]
      provider: fontProviders.google(),
      fallbacks: ["monospace"],
      weights: [300, 400, 500, 600, 700],
      styles: ["normal", "italic"],
    },
  ],
});
```

2. **更新 `Layout.astro` 中的字体组件：**

```astro file="src/layouts/Layout.astro"
---
import { Font } from "astro:assets";
// ...
---

<head>
  <!-- ... -->
  <Font
    cssVariable="--font-your-font"
    preload={[{ subset: "latin", weight: 400, style: "normal" }]}
  />
  <!-- ... -->
</head>
```

3. **更新 `src/styles/theme.css` 中的 CSS 变量映射：**

```css file="src/styles/theme.css"
@theme inline {
  --font-app: var(--font-your-font); /* [!code highlight] */
  /* ... */
}
```

`--font-app` 变量通过 `font-app` Tailwind 实用工具类在整个主题中使用，因此更新这个单一变量即可将自定义字体应用到所有地方。

> [!WARNING]
> 确保字体名称与 [Google Fonts](https://fonts.google.com) 上显示的名称完全一致。对于其他字体提供程序或本地字体，请参阅 [Astro 字体文档](https://docs.astro.build/en/guides/fonts/)。
